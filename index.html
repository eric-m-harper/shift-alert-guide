Shift Alert Automation — Setup Guide

Two automated flows that DM you privately in Teams whenever a shift has fewer than 2 employees. No coding required.

📊 Excel (OneDrive) ⚡ Power Automate 💬 Microsoft Teams ⏱ ~30–45 min setup
✓

Prerequisites

1

Prepare your Excel file

Required columns
Column nameExampleNotes
ShiftDate06/15/2025Must be Date-formatted, not Text
ShiftNameMorning ShiftLabel shown in the alert
StartTime08:00 AMOptional — appears in the alert message
EmployeeCount1Number of employees scheduled
Convert your data to a named table
  1. Click any cell inside your data
  2. Press Ctrl + T and check "My table has headers" → click OK
  3. In the Table Design tab → Table Name field, name it ShiftSchedule
  4. Save the file to OneDrive
2

Open Power Automate

  1. Go to flow.microsoft.com and sign in
  2. Click Create in the left sidebar
  3. Select Scheduled cloud flow
3

3e — YES branch: send Teams DM to yourself
  1. Inside the If yes box → click Add an action
  2. Search Microsoft Teams → select Post a message in a chat or channel
Post asUser
Post inChat with myself
MessageUse the template below
⚠️ SHIFT ALERT — 48 Hour Warning The following shift(s) in 2 days have fewer than 2 employees: Shift: [ShiftName] Date: [ShiftDate] Start Time: [StartTime] Employees Scheduled: [EmployeeCount] Please arrange cover as soon as possible.
💡 Replace the bracketed placeholders by clicking into the message field and selecting the matching column names from the Dynamic content panel on the right.
ℹ️ Leave the NO branch empty — if no understaffed shifts are found, the flow simply ends silently.
3f — Save and test
  1. Click Save in the top right
  2. Click Test → select Manually → click Test
  3. Check your Teams chat with yourself for the alert
✅ Flow 1 is complete. You should see the test message appear in your Teams DM to yourself.

Troubleshooting

ProblemFix
"File not found" errorMake sure Excel is saved to OneDrive, not your local desktop
No dynamic content showingYour Excel data must be a named Table — not just a plain range
Flow runs but no message sentFilter found no matches — check ShiftDate is formatted as Date, not Text
Date filter not matchingEnsure ShiftDate cells use Date format in Excel, not Text format
"Post as User" option missingTry "Post as Flow Bot" — admin permissions may be required for User mode
✨

Optional enhancements

Email backupAdd an Outlook "Send email" action alongside the Teams message
Multi-shiftAlready handled — each matching row triggers its own line in the message
EscalationAdd a second Teams message to a manager if still understaffed 24 hours out
Snooze logicUse a SharePoint list to track acknowledged alerts and avoid repeat pings
